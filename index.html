02 — Reproducible R calculations

Real R code. Clear predictions.

Linear regression fits the built-in mtcars data (32 cars).

cars <- mtcars
cars$transmission <- factor(
  cars$am, levels=c(0,1),
  labels=c("Automatic","Manual"))
fit <- lm(mpg ~ wt + hp +
  transmission, data=cars)
round(mean(mtcars$mpg), 2)
